# Porilo

Porilo is an offline day planner for Android (React Native / Expo) — no backend, no account, no analytics, nothing ever leaves your device.

## Name

**Porilo** = *pora* (Polish: "time of day") + *-ilo* (Esperanto suffix meaning "tool") — a tool for the time of your day.
